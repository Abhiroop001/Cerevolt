# Cerevolt Frontend (Vite + React + Tailwind)

## Quick start

1. Install dependencies:
npm install

2. Start the mock json-server (port 4000):

npm run mock


3. In a parallel terminal, start the dev server:

npm run dev


4. Open http://localhost:5173

## Notes
- Mock API served at http://localhost:4000
- Login with test users from `mock/db.json`
- App uses localStorage to store token (`cv_token`) in this starter. Replace with secure cookies in production.
